# สิ่งที่เปลี่ยนตั้งแต่ main (0426f37)

สรุปสำหรับคนทั่วไปและใช้ประกอบการนำเสนอ — เปรียบเทียบ branch `feature/polish` กับ `main` (53 commit + รอบขัดเกลา) รายละเอียดเทคนิคอยู่ที่ `docs/ROADMAP.md`

## การระบาย
- **สีน้ำแห้งเอง:** หลังปล่อยมือ น้ำไหลต่ออีกครู่แล้วสงบลงใน ~10 วินาที สีไม่จางหายไปเลย (แก้บัคที่สีค่อย ๆ หายใน 1 นาที)
- **สาดสีตอนเข้าหน้าระบาย:** หยดสีทยอยลงตามอารมณ์ (พุ่งกระจาย ไหลช้า ตกลงล่าง ฯลฯ) ภายใน 1 วินาที พื้นที่สีใหญ่ขึ้นตามความเข้ม
- **สีไม่ดำ:** ตัวกันดำย้ายไปทำงานที่การ์ดจอ ระบายซ้ำกี่ครั้งสีก็ไม่ทับกันจนเป็นดำหรือเทา
- **แต้มแสง (สำหรับอารมณ์ลบ):** ผู้ใช้เลือกเองเท่านั้น หยดสีอุ่นบานออกอย่างนุ่มนวลเป็นรอยเดียว มีโน้ตชวนลองครั้งเดียวต่อแผ่น และปุ่ม "ลองดู"
- **พู่กันจุ่มสีที่หน้าเลือกความรู้สึก:** พู่กันตัวใหญ่เลื่อนไปการ์ด จุ่มลงน้ำ ปลายขนเปลี่ยนสีตามอารมณ์
- **เคอร์เซอร์วาดมือ:** นิ้วชี้ทั่วแอป บนผ้าใบเป็นนิ้วติดสี/พู่กันสีอารมณ์/พู่กันสีอุ่นตามเครื่องมือ
- **โน้ตอารมณ์พับเก็บ:** เริ่มแตะผ้าใบแล้วโน้ตเลื่อนหลบเป็นแถบเล็กที่ขอบขวา ไม่บังภาพ กดเปิดกลับได้

## เสียงและแสง
- **เสียงเอฟเฟกต์:** สังเคราะห์สดทั้งหมด (หยดน้ำ ปาด สาด แต้มแสงบาน กระดาษลอย เทป พลิกแผ่น แตะปุ่ม) ไม่ใช้ไฟล์เสียง เปิด/ปิดได้
- **เพลงคลอ:** วนต่อเนื่อง เปลี่ยนเพลงกลางวัน/กลางคืนอย่างนุ่มนวล (ตอนนี้เป็นเพลงตัวอย่างรอเพลงจริง) เบากว่าเอฟเฟกต์ และเบาลงอัตโนมัติตอนบันทึก
- **แสงตามเวลาจริง:** โต๊ะเปลี่ยนบรรยากาศกลางวัน / เย็น / กลางคืน (มีแสงตะเกียงและฝุ่นลอยตอนกลางคืน) โดยไม่แตะสีบนผ้าใบหรือภาพในสมุด
- **ภาพยังเปียก:** ภาพที่เพิ่งแปะและภาพที่เปิดดูเดี่ยวพลิ้วเบา ๆ ราว 3 วินาทีก่อนนิ่ง

## สมุด
- **พลิกสมุดแบบ 3 มิติ:** เปิด/ปิดปกพลิกรอบสันสมุดพร้อมเงา (หน้าแรก ↔ สมุด, ระบาย → สมุด, ตอนบันทึก) และพลิกหน้ากระดาษตอนเปลี่ยนแผ่นหรือเปลี่ยนวัน
- **หน้าจานสีประจำวันใหม่:** ก้อนสีของวันอยู่ในกรอบกระดาษเอียงเล็กน้อย + **แถบสีของวัน** เป็นรอยพู่กันเส้นเดียวไล่สีตามลำดับเวลา (ภาพติดกันที่อารมณ์เดียวกันรวมเป็นช่วงเดียว ป้ายเวลาเยื้องแถวไม่ทับกัน)
- **การ์ดหลังบันทึก:** อยู่ในหน้าขวาของสมุด มีแถบสีถูกปาดทีละช่วง และชื่อสีของวันเปลี่ยนให้เห็น
- **ภาพแต่ละใบ:** ชิป "สีในภาพนี้" ที่สีจางมากมีขอบบาง ๆ ให้เห็นบนกระดาษ
- **หน้าตั้งชื่อสมุด:** "สิ่งที่ทำให้ใจฟู" เลือกได้สูงสุด 3 อย่าง มีตัวนับ
- **โลโก้ ColorScrap** ใช้ชุดเดียวกันทั้งแอป favicon และการ์ดที่เก็บเป็นรูป

## เก็บรูป
- **เก็บเป็นรูป PNG ในเครื่อง** (ไม่อัปโหลดไปไหน): การ์ดภาพพร้อมชาร์ตสี, เฉพาะภาพ และ **การ์ดจานสีของวัน** (ออกแบบใหม่: โลโก้ กรอบสีของวัน แถบสีตามลำดับเวลา ภาพย่อ 3 ใบ "+N ภาพ")
- iPad เปิดหน้าแชร์ให้กด "บันทึกรูปภาพ" คอมพิวเตอร์ดาวน์โหลดเป็นไฟล์ ชื่อผู้ใช้บนการ์ดถูกปิดบางส่วนเพื่อความเป็นส่วนตัว

## ระบบและความมั่นคง
- **บัญชีผู้ใช้จริง (Supabase):** สมัคร/เข้าสู่ระบบ ข้อมูลและรูปแยกรายคน เหมาะกับเครื่องที่คนใช้ผลัดกัน (ออกจากระบบแล้วล้างสถานะ)
- **อัปโหลดอัตโนมัติ:** บันทึกในเครื่องก่อน แล้วอัปโหลดเบื้องหลัง ลองใหม่เองเมื่อเน็ตหลุด
- เทสต์อัตโนมัติ 150+ ตัวสำหรับสูตรสี จานสีของวัน ตัวกันดำ เสียง เพลง เก็บรูป ฯลฯ

## แก้บัค / เก็บงาน
- แก้บัคสีจางหายเอง, สีอุ่นไม่ออก, สีอุ่นเด้งเป็นจังหวะที่สอง, ผ้าใบว่างทั้งผืนเมื่อค่าน้ำผิดปกติ
- ปุ่มทุกตัวมีพื้นที่กด ≥ 44px (เหมาะกับนิ้วบน iPad)
- ทุกแอนิเมชันมีทางเลือกสำหรับผู้ที่เปิด "ลดการเคลื่อนไหว"
- สีเทาที่เขียนซ้ำหลายที่รวมเป็นชุดเดียวใน `tokens.js` (หน้าตาเหมือนเดิมทุกพิกเซล)
- ลบโค้ดที่ไม่ใช้แล้ว และปรับเอกสาร (SPEC, FILE-GUIDE) ให้ตรงกับของจริง
