# สเปก: สีน้ำที่ค่อย ๆ แห้ง (ส่วนที่ 1)

อัปเดต 13 ต.ค. 2569 · branch `feature/fluid-tuning`

## เป้าหมาย
คอมเมนต์อาจารย์: "สีน้ำซีดลงและหายไปเร็วเกินไป"

ผู้ใช้ต้องการแค่ให้สีไม่ซีด ส่วนการไหลให้เหมือนก่อนวันที่ 12 ต.ค. ทุกอย่าง แต่น้ำต้องไม่ขยับไปตลอดเวลา

**ภาพรวมของพฤติกรรม**
1. สาดสีเข้าหน้า canvas
2. น้ำไหลเหมือนเดิม (ค่าของ main)
3. น้ำค่อย ๆ ช้าลง แล้วนิ่งสนิทภายในราว 10 วินาทีหลัง input ล่าสุด
4. สีอยู่ถาวร ไม่จาง

## สิ่งที่รู้แล้วจากการวัด (ห้ามแก้กลับ)
- บัฟเฟอร์สีของไลบรารีเป็น half float (RGBA16F)
  - ค่า `DENSITY_DISSIPATION` ใด ๆ ที่มากกว่า 0 ถูกปัดเศษทุกเฟรม สีจึงหายราว 90% ใน 60 วินาที
  - ต้องตั้งเป็น `0` พอดี
- ค่าของ main ทำให้น้ำไหลไม่หยุดเลย (ความเร็วสูงสุดค้างอยู่ที่ 3–28)
  - เมื่อก่อนไม่มีใครเห็น เพราะสีจางหายไปก่อน
- ผู้ใช้ไม่ชอบกลไกสองตัวนี้:
  - `bleed`: เติมสีเป็นวงจนดูเหมือน airbrush
  - `drift`: น้ำพาสีให้ไหลต่อ

## ต้องทำ
1. **tag** `tuning-v2` ที่ commit ปัจจุบันก่อนเริ่ม
2. **ลบ `bleed` และ `drift` ทั้งหมด**: ทั้งโค้ด ค่าคงที่ slider ใน `?debug` และเอกสาร
3. **หน้าตาแต่ละอารมณ์ใช้ค่าจาก main**
   - ได้แก่ brightness, speed, curl, velDiss, radius, จำนวนหยด, pattern
   - ย้อนไว้แล้วใน `5e5fea5` ตรวจซ้ำว่าตรงกับ main
4. **เก็บไว้**
   - `DENSITY_DISSIPATION = 0`
   - `INK_CAP` คิดทุกช่องที่หยดแตะ
   - การแก้หน่วงทั้งหมด: รวม splat ต่อเฟรม, pressure 12, dye 768/512, cache rect, ข้าม dye pass ตอนดันน้ำ, อ่านความเร็วแบบ async
   - การสาดสีแบบทยอยลง
5. **ใหม่: น้ำสงบลงเอง (drying)**
   - นับเป็น input: แตะ, ลาก/ปาด, กดค้าง, หยดสีอุ่น, การสาดตอนเข้าหน้า (นับเวลาจากหยดสุดท้ายของการสาด)
   - ช่วง ~2.5 วินาทีแรกหลัง input: velocity dissipation เป็นค่าปกติของอารมณ์ ไหลเหมือน main ทุกอย่าง
   - หลังจากนั้น: ค่อย ๆ เพิ่ม velocity dissipation แบบ ease-in-out จนน้ำเกือบหยุดที่ ~10 วินาที
     - ห้ามหยุดกะทันหัน
     - ห้ามแตะ density
   - เมื่อมี input ใหม่: กลับเป็นค่าปกติทันที
     - บริเวณที่นิ่งไปแล้วจะไม่ขยับ เพราะความเร็วตรงนั้นเป็นศูนย์อยู่แล้ว
   - เมื่อความเร็วสูงสุดต่ำกว่า `STILL_SPEED`: ให้การพักการจำลองทำงาน (ใช้กลไกเดิม)
   - slider ค่ากลางใน `?debug`:
     - "เวลาจนแห้ง (วินาที)" ค่าเริ่มต้น 10 ช่วง 4–30
     - "ไหลปกติก่อนเริ่มแห้ง (วินาที)" ค่าเริ่มต้น 2.5
6. **การสาดสีตามระดับ**: พื้นที่สีหลังสาดต้องเป็น ~2 เท่าของ main ครบทั้ง 8 อารมณ์
   - main ที่วัดจริง (13 ต.ค. 2569, `measure-fluid.mjs`, 3 seed, วินาทีที่ 8; ตัวเลขเดิมในสเปกนี้ผิด):
     - สงบ 9.0 / 15.9 / 25.0
     - ตื่นเต้น 19.0 / 30.1 / 45.9
     - เศร้า 8.5 / 15.3 / 28.6
   - อีก 5 อารมณ์ (สุขใจ อบอุ่นใจ โกรธ กังวล เหนื่อย): วัดค่าของ main ก่อน แล้วจูน `splash` ต่ออารมณ์ (เป้าที่อนุมัติอยู่ใน SPEC §6.3 "มากเลย" จำกัด ~75–78%)
   - ตื่นเต้น "มากเลย" ต้องมากกว่า "พอประมาณ" ชัดเจน (เป้าราว 55%)
   - ต้องวัดหลังใส่ข้อ 5 แล้ว เพราะการสงบทำให้พื้นที่เปลี่ยน
   - `INTENSITY_FACTOR` และสูตรจานสีของวัน (`palette.js`) ห้ามแก้
7. **Reduce Motion**: เหมือนเดิม (ไม่สาดเป็นจังหวะ fade 150ms)
8. **อัปเดตเอกสาร** `SPEC.md`, `CLAUDE.md`, `docs/FILE-GUIDE.md` ให้ตรงกับกลไกที่เหลือจริง รวมเหตุผลเรื่อง fp16

## เกณฑ์ผ่าน (ทดสอบเองด้วย `scripts/measure-fluid.mjs` และ `scripts/measure-fps.mjs`)
| ข้อ | เกณฑ์ |
|---|---|
| สีไม่จาง | ความเข้มรอบจุด 60 วิ ÷ 5 วิ ≥ 95% ทุกอารมณ์ |
| น้ำหยุด | ผลต่างพิกเซลเฉลี่ยระหว่างวินาทีที่ 15 กับ 60 ≤ 0.1 (จาก 255) |
| ช่วงแรกเหมือน main | พื้นที่สีที่ 2 วิ ต่างจาก main ไม่เกิน ±10% |
| ไม่ขุ่น | ระบาย 3 สีแยกกัน ปล่อย 3 นาที: ตำแหน่งกึ่งกลางของแต่ละสีขยับ < 3% ของความกว้างผ้าใบ |
| ไม่ดำ | ระบายจุดเดิม 2 นาที: พิกเซลมืดสุดไม่ต่ำกว่าเดิม (≥ ~20%) |
| สาดสี | ทั้ง 8 อารมณ์ × 3 ระดับ อยู่ในช่วง ±12% ของ 2×main |
| FPS | ไม่ต่ำกว่าผลรอบก่อน และการพักการจำลองต้องทำงานหลังน้ำนิ่ง |
| ระบบ | `npm test` และ `npm run build` ผ่าน |
