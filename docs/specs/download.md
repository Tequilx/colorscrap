## 1. หน้าเปิดดูภาพ (PhotoView)
**ห้ามเปลี่ยนหน้าตาเดิม** ได้แก่ โพลารอยด์ซ้าย, แผง "สีในภาพนี้", ปุ่ม "× ปิด", แถบสีรายสี, แถบรวม

เพิ่มส่วนท้ายแผง ต่อจากแถบรวม:
- เส้นประคั่น
- หัวข้อ "เก็บรูปไว้" (Mali 600 16px)
- ปุ่มสองปุ่มเรียงแถว gap 10px สูงอย่างน้อย 52px:
  - **ปุ่มหลัก** (พื้นหมึก `ink`, ตัวอักษร `paper`, ไอคอนลูกศรลง, ยืดเต็มที่ว่าง): "การ์ดพร้อมชาร์ตสี"
  - **ปุ่มรอง** (พื้นขาว, ขอบหมึก 2px, ไอคอนรูปภาพ): "เฉพาะภาพ"
- ข้อความเล็ก 12px สี `ink-soft`
  - แสดงเฉพาะอุปกรณ์ที่รองรับแชร์ไฟล์: บน iPad จะเปิดหน้าแชร์ กด "บันทึกรูปภาพ" เพื่อเก็บลงคลังรูป
  - อุปกรณ์อื่นแสดง: ไฟล์จะถูกดาวน์โหลดเป็น PNG

**สไตล์ปุ่ม**
- มุมโค้งไม่เท่ากันแบบวาดมือ เช่น `16px 20px 14px 18px`
- filter `wob`
- hover เฉพาะอุปกรณ์ที่มีเมาส์

**ตำแหน่งแผง**: ถ้าแผงสูงขึ้นจนล้นจอ 1280×800 ให้ขยับตำแหน่งแผงขึ้น ห้ามย่อขนาดตัวอักษร

## 2. หน้าสมุด (หน้าขวา)
- แถวหัวข้อเป็น `display:flex; justify-content:space-between; align-items:center`
- ด้านซ้ายเป็นคอลัมน์ "จานสีของวันนี้" (Mali 600 26px)
- ใต้หัวข้อมีบรรทัดเล็ก "N ภาพ · M อารมณ์" (13px `ink-soft`) ย้ายมาจากมุมขวาเดิม
- ด้านขวาเป็นปุ่ม "เก็บรูป":
  - ไอคอนลูกศรลง + ข้อความ
  - สูงอย่างน้อย 44px ขอบ 2px พื้นขาว filter `wob`
  - `aria-label="เก็บจานสีวันนี้เป็นรูป"`
- **วันที่ไม่มีภาพ**: ปุ่ม disabled (opacity ~0.4, `aria-disabled`)
- กดแล้วสร้างการ์ดจานสี **ของวันที่กำลังเปิดดู** ไม่มีเมนู
- หยดสีในแถบ "ช่วงเวลาของวัน" **ใช้แบบเดิม** (หยดน้ำ) ยังไม่ต้องเปลี่ยน

**ส่วนหัว**

- ขวา: วันที่ไทย พ.ศ. แบบ `อังคาร 13 ตุลาคม 2569` (26px `ink-soft`)

## 5. รูป "เฉพาะภาพ"
- ภาพที่บันทึกไว้ตามความละเอียดเดิม แปลงเป็น PNG
- ไม่มีกรอบหรือข้อความ

## 6. การเซนเซอร์ชื่อ: `maskName(name)` ใน `src/lib/share/maskName.js`
- ตัดช่องว่างหัวท้าย แล้วแบ่งตาม **grapheme** ด้วย `Intl.Segmenter('th', { granularity: 'grapheme' })`
  - มี fallback เมื่อไม่มี Segmenter: รวมสระบน/ล่างและวรรณยุกต์ไทยเข้ากับพยัญชนะก่อนหน้า
- กติกา:
  - ว่าง → `''` (ซ่อนบรรทัด "โดย")
  - 1–2 grapheme → ตัวแรก + `•`
  - 3 grapheme ขึ้นไป → ตัวแรก + `•` × min(n−2, 3) + ตัวสุดท้าย
- ตัวอย่าง:
  - สมใจ → ส••จ
  - ศศิธร → ศ••ร
  - มด → ม•
  - Alexander → A•••r
- ใช้ชื่อที่ผู้ใช้ตั้งในหน้า hello/โปรไฟล์

## 7. ตัวช่วยอื่น (`src/lib/share/`)
- `formatThaiDate(date)` → `อังคาร 13 ตุลาคม 2569` (ชื่อวันไม่มีคำว่า "วัน", ปี พ.ศ.)
- `percentsOf(colors)`: ใช้ของเดิมถ้ามี ผลรวมต้องเป็น 100 ด้วยวิธี largest remainder
- ชื่อไฟล์:
  - การ์ดภาพ: `colorscrap-YYYY-MM-DD-HHmm.png`
  - เฉพาะภาพ: `colorscrap-photo-YYYY-MM-DD-HHmm.png`
  - การ์ดวัน: `colorscrap-day-YYYY-MM-DD.png`
  - ใช้เวลาท้องถิ่นของภาพ

## 8. วิธีสร้างรูป
- วาดด้วย **Canvas 2D** ขนาด 1080×1350 แล้ว `toBlob('image/png')`
  - ห้ามใช้ html-to-image หรือ foreignObject เพราะ Safari ไม่เสถียร
- **ฟอนต์**: `await document.fonts.load()` ให้ครบทุกน้ำหนักที่ใช้ (Mali 600/700, IBM Plex Sans Thai Looped 400) ก่อนวาด
- **ความรู้สึกวาดมือ** (SVG filter ใช้ใน canvas ตรง ๆ ไม่ได้ ให้วาดเลียนแบบ):
  - แถบสี: ขอบไม่เรียบด้วย noise เล็กน้อย
  - เส้นประ
  - เทปกึ่งโปร่งใส
  - grain: สร้าง noise pattern ครั้งเดียวแล้ว cache
  - หลุมผสมสี: วงซ้อนโปร่งใสหลายชั้น
- **ภาพจาก Supabase** (bucket private):
  - `fetch(signedUrl)` → blob → `createImageBitmap` แล้วค่อยวาด เพื่อไม่ให้ canvas tainted
  - โหมด mock อ่าน blob จาก IndexedDB
- ทำทั้งหมดในเครื่อง ห้ามอัปโหลด และห้ามส่งข้อมูลไปที่อื่น

## 9. การส่งรูปให้ผู้ใช้: `shareOrDownload(blob, filename)`
**กรณีแชร์ได้** (`navigator.canShare?.({ files: [file] })` เป็นจริง)
- เรียก `navigator.share({ files: [file] })`
- ถ้าผู้ใช้กดยกเลิก (`AbortError`): เงียบ ไม่ขึ้น error
- ถ้าเจอ `NotAllowedError` (การแชร์หลุดจากจังหวะที่ผู้ใช้กด เพราะสร้างรูปนาน):
  - เก็บไฟล์ไว้
  - แสดง toast พร้อมปุ่ม "แตะเพื่อบันทึก" ที่เรียก share ใหม่ใน gesture ใหม่

**กรณีแชร์ไม่ได้** (เช่น desktop หรือ http ผ่าน IP): ดาวน์โหลดด้วย `<a download>` + object URL แล้ว revoke ทีหลัง

**สถานะระหว่างทำรูป**
- ปุ่มที่กดเปลี่ยนเป็น "กำลังทำรูป…" และ disabled
- กันกดซ้ำ
- ปุ่มอื่นยังใช้ได้

**เมื่อเสร็จ**: toast "เก็บรูปแล้ว" (ใช้ Toast เดิม)

**เมื่อพลาด**: toast "ทำรูปไม่สำเร็จ ลองอีกครั้งนะ" + `console.error`

**Reduce Motion**: ไม่มีแอนิเมชันเพิ่มนอกจาก toast fade
