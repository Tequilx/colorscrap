ทำ / ไม่ทำ

  • ใช้แปรงเดียว เส้นหนาเดียว สีเส้นเดียว (Graphite) ทุก asset
  • เว้นพื้นที่ว่างเยอะ ๆ ให้เหมือนกระดาษที่ยังไม่ได้เขียน
  • สีสดใช้เฉพาะอารมณ์และงานสีน้ำ ส่วน UI ใช้ขาวเทาดำ
  • ขอบเส้นไม่ต้องปิดสนิท ให้เหลือช่องเล็ก ๆ เหมือนวาดจริง
  • ปุ่มบน iPad สูงอย่างน้อย 48px
  • ไม่ใช้เงาหนา ๆ หรือ gradient แบบแอปทั่วไป ยกเว้นเงาบาง ๆ ใต้ภาพที่แปะ
  • ไม่ใช้อีโมจิหรือไอคอนสำเร็จรูปปนกับงานวาด
  • ไม่ใช้ฟอนต์ลายมือกับข้อความยาว
  • ไม่ใช้สีแดงเตือนแบบ error ตอนผู้ใช้เลือกอารมณ์ลบ
  • ไม่ใช้ข้อความสั่งสอน เช่น "อย่าเศร้านะ"
