## ดูแปลกแต่ไม่พัง (ไม่ได้แก้)
- ตอนพลิกปกจากหน้าแรก แท็บสีบนปกปิดหายไปตั้งแต่เริ่มพลิก (ปกที่พลิกไม่มีแท็บ)
- ตอนพลิกปกจาก "ระบาย → สมุด" ปกโผล่ขึ้นมาบนหน้าขวาด้วยการจางเข้า (ไม่มีปกให้เลื่อนมาจากไหน)
- ลำดับบันทึกนานขึ้น 0.3 วิ เพราะรอพลิกปก (ตามสเปก)
- แท็บวันที่ส่วนที่โผล่พ้นปกสูงแค่ 26 px (เดิมก็เท่านี้) ขยายเฉพาะพื้นที่กดให้
- ตรวจ focus ring ด้วยค่า outline ที่คำนวณได้ ถ้าบางปุ่มมีวงโฟกัสแต่ซ่อนด้วยวิธีอื่นอาจไม่เจอ
- เฟรมสะดุด 117 ms ครั้งเดียวตอนปาดสีรอบแรก (น่าจะคอมไพล์ shader) ไม่เกิดซ้ำ
- ไม่ได้สร้าง tag `pre-daycard2` / `pre-photocard2` (ทำข้อ 17–19 ใน commit เดียว ใช้ tag `pre-brandmark`)
- ยังไม่ได้ทดสอบหน้า login/LegacyPrompt (ต้องโหมดจริง) และบน iPad/Safari จริง

## สิ่งที่ผมต้องเช็กด้วยตา/หู (เรียงตามความสำคัญ)
1. พลิกปก 3D บน iPad Safari จริง: ลื่นไหม มีกระตุก/ขอบแหว่ง (perspective + clip-path) ทั้งเปิด ปิด และตอนบันทึก
2. ลำดับบันทึกแล้วรู้สึกช้าไปไหมเมื่อมีพลิกปก (+0.3 วิ) และภาพโพลารอยด์ลงช่องหลังปกลงจอดดูเป็นธรรมชาติ
3. เสียงทั้งหมด (พลิกปก, โน้ตพับ, ปาด, สาด, แต้มแสง) ฟังจริงบนลำโพง iPad ระดับเสียงเพลงกับเอฟเฟกต์
4. การ์ดจานสีของวัน (PNG ที่ได้) เทียบภาพ 12 ด้วยตา โดยเฉพาะป้ายใต้แถบเมื่อมีหลายช่วง และกรณี 13 ภาพ
5. หน้า hello: ใจฟูครบ 3 แล้วชิปจางอ่านออกไหม ข้อความ "ครบแล้ว…" ชัดพอ
6. โน้ตอารมณ์พับ: แถบที่ขอบขวาไม่รบกวนและเจอง่ายพอสำหรับเด็ก/ผู้ชมงาน
7. พลิกแผ่น/เปลี่ยนวันตอนข้อมูลเยอะ (หลายแผ่น) ดูเป็นหน้ากระดาษจริงไหม
8. วิดีโอเดโมทั้งสองไฟล์ (จังหวะช้าพอ ตามทันไหม) และเพิ่มเสียงตอนตัดต่อเอง
9. หน้า login + deploy จริงตาม `docs/DEPLOY.md` (ยังไม่เคยทดสอบโหมดจริงในรอบนี้)
10. ฟอนต์ Mali/IBM Plex ตอนเน็ตไม่เสถียร (ยังโหลดจาก Google Fonts)
